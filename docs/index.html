How It Works
From zero to trading
in 60 seconds.
01
Install
One pip command. No Docker, no infra, no config files.
$ pip install hashtrade
02
Configure
Pick your AI provider and optionally add exchange API keys. Or just run with defaults — Ollama is free and local.
$ export MODEL_PROVIDER="bedrock"
$ export STRANDS_MODEL_ID="global.anthropic.claude-opus-4-6-v1"
$ export CCXT_API_KEY="your_key"
$ export CCXT_SECRET="your_secret"
$ export CCXT_EXCHANGE="your_exchange"
03
Launch
Start the server and open the dashboard. The agent connects, syncs its memory, and starts watching the markets.
$ hashtrade
04
Vibe
Talk to it. Tell it what to watch. Set your trading style. Then let it run. It'll wake up, analyze, trade, and log everything — 24/7.
